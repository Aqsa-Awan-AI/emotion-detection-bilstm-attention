# 🧠 Emotion Detection using BiLSTM with Attention

An end-to-end Natural Language Processing (NLP) project that detects human emotions from conversational text using a **Bidirectional Long Short-Term Memory (BiLSTM)** network with an **Attention Mechanism**.

This project demonstrates the complete deep learning pipeline—from data preprocessing and exploratory data analysis (EDA) to model training, evaluation, and real-time emotion prediction. It is implemented in **Google Colab** using **TensorFlow/Keras** and can classify emotions from custom text inputs.

---

## 📌 Project Overview

Emotion Detection is one of the most important tasks in Natural Language Processing (NLP). It enables machines to understand the emotional meaning behind human conversations instead of only identifying whether text is positive or negative.

In this project, a **BiLSTM with an Attention layer** is used to learn contextual relationships within text sequences. The model analyzes conversational text and predicts the most appropriate emotion while assigning a confidence score to each prediction.

The notebook covers the complete machine learning workflow, making it suitable for learning deep learning-based text classification.

---

## ✨ Key Features

- 📂 Load and explore conversation-based emotion datasets
- 📊 Perform Exploratory Data Analysis (EDA)
- 🧹 Text preprocessing and cleaning
- 🔤 Tokenization and sequence padding
- 🧠 Build a BiLSTM with Attention model
- 📈 Train and validate the deep learning model
- 🎯 Predict emotions for custom user input
- 💾 Save the trained model and tokenizer
- 📋 Display confidence scores for predictions
